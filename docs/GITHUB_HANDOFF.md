# GitHub handoff

The public repository is https://github.com/WithyDiamond466/agora-v2. Soren approved public publication and the MIT license. The front page links separate setup and contribution guides for professors and developers.

The initial public commit contains reviewed application code, tests, documentation, and synthetic examples. Local coursework, credentials, machine settings, and internal build logs are excluded. Original development history remains on the local `ready-fall` branch; it is not part of the public snapshot.

GitHub Actions runs dependency installation, offline tests, template/page checks, JavaScript syntax checks, and the mock workflow on Windows, macOS, and Linux. See [current status](../STATUS.md) for results and the remaining live-provider and instructor acceptance work. This is a development preview, not a qualified classroom release.
